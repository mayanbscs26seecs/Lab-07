# Storage Estimator

## Purpose
A small Python program that estimates how much storage is needed
for a given number of files of an average size.

## How to Run
1. Install Python 3.
2. Open a terminal in this folder.
3. Run: python storage_estimator.py

## Example
Input:
    Number of files: 200
    Average size of one file (MB): 2.5
Output:
    Total storage needed: 500.00 MB
